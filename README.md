# QFun 插件包

在 QQ 里用的 QFun 小插件，直接导入 zip 即可。

## 下载

| 插件 | 文件 | 直链 |
|---|---|---|
| 群快捷栏 | `qfun-shortcut.zip` | https://github.com/ab007227ab-alt/qfun/raw/main/qfun-shortcut.zip |
| 读群快捷栏 | `qfun-reader.zip` | https://github.com/ab007227ab-alt/qfun/raw/main/qfun-reader.zip |
| 上传图床 | `upload-imagehost.zip` | https://github.com/ab007227ab-alt/qfun/raw/main/upload-imagehost.zip |
| 弹一句话 | `qfun-popup.zip` | https://github.com/ab007227ab-alt/qfun/raw/main/qfun-popup.zip |

国内加速：在上面链接前加 `https://ghproxy.net/`，例如
`https://ghproxy.net/https://github.com/ab007227ab-alt/qfun/raw/main/qfun-shortcut.zip`

## 安装

1. QFun → 插件管理 → 导入 zip
2. 重启 QQ
3. 聊天界面悬浮菜单里出现对应入口

## 说明

- 群快捷栏：表单新增/修改群快捷栏按钮，内置 `mqqapi://zplan/toast?msg=` 一键预设，点一下就在群里弹一句原生提示
- 读群快捷栏：只读查询当前群快捷栏原始数据（appId / 图标 / 跳转），可复制成填表格式
- 上传图床：本地图片压缩后传 imgbb 拿直链，支持填代理地址走自建 Worker
- 弹一句话：QQ 内原生弹窗，几秒自动淡出
